# Evaluation

No performance values should be reported until measured on appropriate data.

Planned metrics include IoU, Dice, precision, recall, F1, origin error, trajectory error, Top-1 accuracy, Top-3 recall, MRR, nDCG, citation accuracy, and faithfulness.

The current `/api/v1/evaluations` endpoint reports only development fixture checks. These values verify pipeline wiring and ranking behavior; they are not model performance claims.
